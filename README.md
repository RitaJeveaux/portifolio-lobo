# Portfólio Lobo 🐺

Este é um projeto de site de portfólio para um Desenvolvedor Front End e UX/UI Designer, criado para demonstrar habilidades em HTML e CSS.

## 🚀 Visualizar Projeto

Você pode acessar a versão ao vivo do site aqui:

**[https://ritajeveaux.github.io/portifolio-lobo/](https://ritajeveaux.github.io/portifolio-lobo/)**

## ✨ Funcionalidades

O site é uma página única (single-page) que inclui as seguintes seções:

- **Introdução:** Breve apresentação do profissional.
- **Experiência:** Detalhes sobre projetos e cargos anteriores.
- **Formação:** Histórico acadêmico, cursos e idiomas.
- **Contato:** Informações para contato e um convite para novos projetos.

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Para a estrutura semântica do conteúdo.
- **CSS3:** Para estilização, layout e responsividade.

## 📂 Como Executar Localmente

1.  Clone este repositório para a sua máquina local.
2.  Abra o arquivo `index.html` em seu navegador de preferência.
